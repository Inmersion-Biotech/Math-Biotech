# Third-party software and learning assets

This project uses open-source dependencies declared in `package.json` and `package-lock.json`. **Every dependency retains its own upstream license** and notices. Bundled source is not a claim of ownership of third-party packages.

Before a public software release:
- Generate and review a dependency inventory/SBOM; resolve incompatible or restricted licenses.
- Review third-party images, fonts, models, reference tables, scientific data and educational documents separately.
- Preserve notices required by the applicable upstream licenses.
- Do not sublicense classroom/examination documents, private study materials, institutional assets or imported media without permission.

This file is a **review reminder**, not a completed clearance certificate. See [CONTENT_POLICY.md](CONTENT_POLICY.md) and [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md).
